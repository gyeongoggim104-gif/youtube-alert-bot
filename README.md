# 유튜브 알림 디스코드 봇 🔔

좋아하는 유튜버가 **영상을 올리거나 생방송을 켜면** 디스코드로 알려 주는 봇이에요.
**사람마다 자기 알림방 2개(🎬 영상 / 🔴 생방)**가 생겨서, 내가 추가한 유튜버 알림만 와요. (티켓방처럼요!)

> 일반 멤버끼리는 서로의 방을 볼 수 없어요. 단, 디스코드 규칙상 **관리자와 서버장은 모든 방을 볼 수 있어요.**

```
📁 유튜브 알림
 ├ #🔔-알림신청     ← 모두 보이는 방. "내 알림방 만들기" 버튼이 있어요
 ├ #🔔-철수-영상    ← 철수의 새 영상 알림
 ├ #🔔-철수-생방    ← 철수의 생방송 알림
 └ #🔒-봇-저장소    ← 기록 보관 (지우지 마세요)
```

- 구글 로그인이나 API 키가 **필요 없어요.**
- 버튼만 눌러서 쓸 수 있어서 **휴대폰에서도 편해요.**

---

## 🛠️ 처음 설정 (서버 관리자가 한 번만)

### 1단계. 봇을 서버에 초대하기 (관리자 권한 포함)
아래 주소의 `봇번호` 자리에 봇의 **애플리케이션 ID**를 넣어서 열어요.
```
https://discord.com/oauth2/authorize?client_id=봇번호&permissions=8&scope=bot%20applications.commands
```
→ 서버 고르기 → **계속하기** → **승인**

### 2단계. 봇 켜기 (24시간)
GitHub 저장소를 연결해서 Python을 실행해 주는 곳이면 어디든 돼요.
(예: Northflank, Railway, 무료 디스코드 봇 호스팅 사이트)

- 실행 명령: `python bot.py`
- 환경 변수(Variables)에 **`DISCORD_TOKEN`** 하나만 넣으면 돼요.

✅ 디스코드에 `유튜브 알림` 카테고리와 `#🔔-알림신청` 방이 생기면 성공!

### 💾 기록은 디스코드에 저장돼요
봇이 관리자만 보이는 **`#🔒-봇-저장소`** 방을 만들고, 누가 어떤 유튜버를 추가했는지 거기에 저장해요.
그래서 봇을 다시 켜거나 **호스팅 사이트를 옮겨도 기록이 그대로 남아요.**
⚠️ 이 방과 그 안의 메시지는 **지우지 마세요!**

## 🙋 사용 방법 (서버 사람 모두)

1. `#🔔-알림신청` 방에서 **🔔 내 알림방 만들기** 누르기
2. 나만 보이는 방이 생겨요 → 들어가기
3. **➕ 유튜버 추가** 누르기 → 유튜브 채널 링크 붙여넣기 → **제출**
   - 링크 찾는 법: 유튜브 앱에서 유튜버 채널 들어가기 → **⋮** 또는 **공유** → **링크 복사**
   - 영상 링크를 넣어도 그 영상의 유튜버가 추가돼요
4. 끝! 이제 그 유튜버가 영상을 올리거나 생방송을 켜면 내 방에 알림이 와요 🎉

| 버튼 | 하는 일 |
|---|---|
| ➕ 유튜버 추가 | 알림 받을 유튜버 추가 |
| 📋 내 목록 | 내가 추가한 유튜버 보기 |
| ➖ 삭제 | 알림 그만 받기 |

명령어로도 똑같이 쓸 수 있어요: `/채널추가`, `/채널목록`, `/채널삭제`, `/알림방`

### 알림 종류
| 알림 | 뜻 |
|---|---|
| 🎬 새 영상이 올라왔어요 | 새 영상 업로드 |
| ⏰ 생방송이 예정됐어요 | 생방송 예약 (시작 시간도 보여 줘요) |
| 🔴 생방송을 시작했어요 | 지금 생방송 중! |
| 📼 지난 생방송 다시보기 | 끝난 생방송 다시보기 |

---

## 알아 두면 좋은 것
- 봇이 **5분마다** 확인해요. 그래서 알림이 몇 분 늦을 수 있어요.
- 유튜버를 추가하기 **전에** 올라온 영상은 알림이 안 가요.
- 알림이 올 때 나를 멘션(@)해서, 휴대폰 알림도 울려요.
- 생방송 구분은 유튜브 영상 페이지를 읽어서 해요. 유튜브가 페이지를 바꾸면 구분이 안 될 수 있어요. 그래도 알림은 "새 영상(또는 생방송)"으로 와요.
